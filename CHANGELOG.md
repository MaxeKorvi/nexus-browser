# Changelog

Все заметные изменения в этом проекте будут задокументированы в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.0.0/),
а проект следует [Semantic Versioning](https://semver.org/lang/ru/).

## [6.0.0] - 2026-01-XX

### Добавлено
- 🔐 **Менеджер паролей** с AES-256-GCM шифрованием через OS keyring
- 👤 **Профили пользователей** с изоляцией cookies и localStorage
- 📥 **Менеджер загрузок** с отображением прогресса и историей
- ⭐ **Закладки** с импортом/экспортом в HTML
- 📜 **История посещений** с поиском и очисткой
- 🔍 **Nexus Search** — собственная новая вкладка с поиском
- 🎨 **Glass UI дизайн** с blur-эффектами и анимациями
- 🌙 **Тёмная/Светлая темы** с авто-переключением
- 📦 **AUR пакет** для Arch Linux
- 🪟 **Windows installer** (NSIS) и portable версия
- 🔒 **Безопасность**: убраны опасные флаги, изоляция профилей

### Изменено
- Улучшена производительность рендеринга вкладок
- Оптимизировано потребление памяти
- Улучшена совместимость с сайтами (Chrome 130 UA)

### Исправлено
- Исправлены утечки памяти при закрытии вкладок
- Исправлено отображение favicon в некоторых случаях
- Исправлена работа контекстного меню

### Безопасность
- Шифрование паролей через AES-256-GCM
- Изоляция данных между профилями
- Отключены опасные Chrome флаги
- WebRTC не сливает локальный IP

## Типы изменений

- `Added` — для новых функций.
- `Changed` — для изменений в существующем функционале.
- `Deprecated` — для скорого удаления функций.
- `Removed` — для удалённых функций.
- `Fixed` — для исправлений ошибок.
