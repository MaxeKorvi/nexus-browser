## 🔒 Сообщение об уязвимости

Если вы обнаружили уязвимость в безопасности, пожалуйста:

1. **НЕ создавайте публичный issue** на GitHub
2. Отправьте email на: security@nexus-browser.local (замените на реальный)
3. Или используйте GitHub Security Advisory (если включено)

### Что указывать в отчёте:

- Описание уязвимости
- Шаги воспроизведения
- Версия браузера
- ОС и версия
- Возможные последствия
- Рекомендации по исправлению (если есть)

## 🛡️ Меры безопасности в Nexus Browser

### Шифрование данных

- **Пароли**: AES-256-GCM через OS keyring
- **Ключи шифрования**: хранятся в системном хранилище ключей
- **Профили**: полная изоляция данных между профилями

### Сетевая безопасность

- **WebRTC**: не сливает локальный IP (`disable_non_proxied_udp`)
- **HTTPS**: приоритет безопасным соединениям
- **CSP**: строгая Content Security Policy

### Изоляция

- **Профили**: отдельные cookies, localStorage, IndexedDB
- **Process isolation**: Electron sandbox для рендереров
- **Контекстная изоляция**: preload скрипты с contextBridge

### Отключённые опасные функции

```javascript
// Убраны опасные флаги:
// --ignore-certificate-errors
// --allow-running-insecure-content
// --no-sandbox
// --disable-gpu-sandbox
```

## 📝 Проверка целостности

### Контрольные суммы релизов

Для каждого релиза публикуются:

- SHA256 хеши файлов
- GPG подписи (планируется)

### Верификация AUR пакета

```bash
# Проверка PKGBUILD перед установкой
cat PKGBUILD | less

# Сборка без установки
makepkg --printsrcinfo > .SRCINFO
makepkg
```

## 🔄 Процесс обновления безопасности

1. Получение отчёта об уязвимости
2. Проверка и подтверждение
3. Разработка исправления (приоритетно)
4. Тестирование
5. Выпуск патч-версии (X.X.Z)
6. Публикация advisory
7. Обновление документации
